# Intrinsic valuation analyst (valuation team)

One member of the fifteen-Bot valuation team for Hermes Agent. Runs the DCF from drivers to a value per share, then says what the market price assumes.

This profile does not work alone: it receives jobs from `valuation-orchestrator` through Bot Mode's
`message_agent`, runs its stage, writes the artifacts the job names, and its final answer
returns to the orchestrator automatically. Chat with it directly to ask about its method.

## Install

Install the whole team from the repository root; the team only works together and only in
the Hermes desktop app with Bot Mode on (Settings → Plugins → Bots):

```bash
tools/install.sh --team valuation
python3 tools/team_models.py valuation --strong <model-id> --fast <model-id>   # optional model tiers
```

This member's tier is **strong**. `tools/install.sh` also writes the profile's Bot
metadata (title and role) so teammates see it in their roster.
