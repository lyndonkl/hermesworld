# Engineering playbooks

This skill contains the standard operating procedures for the engineering team.

## When to Use
- When planning a new feature or architectural change.
- When reviewing code for style and security.

## Best Practices
- Always write tests for new features.
- Keep PRs small and focused.
- Use explicit types and docstrings.
