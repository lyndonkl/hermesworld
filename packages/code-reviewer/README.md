# Code reviewer (engineering team)

One member of the engineering team for Hermes Agent. Reviews architecture decisions, code quality, and writes the final design documentation.

In a team run it receives jobs from `engineering-planner`, runs its stage, writes the artifacts the job
names, and its answer returns to the orchestrator automatically. You can also open it on its
own and ask it to do its stage for a project you name; it will ask for the inputs it needs.

## Install

Install the whole team from the repository root; the team only works together and only in
the Hermes desktop app with Bot Mode on (Settings → Plugins → Bots):

```bash
tools/install.sh --team engineering
python3 tools/team_models.py engineering --strong <model-id> --fast <model-id>   # optional model tiers
```

This member's tier is **writer**. `tools/install.sh` also writes the profile's Bot
metadata (title and role) so teammates see it in their roster.
