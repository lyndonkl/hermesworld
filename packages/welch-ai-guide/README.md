# Welch Labs AI Guide

An interactive, terminal-based tutor for the [Welch Labs Illustrated Guide to AI](https://github.com/stephencwelch/ai_book) repository.

This profile is designed to help you navigate the code, math, and concepts behind neural networks as taught in the Welch Labs series. It will read the repo's code locally, explain backpropagation and gradient descent step-by-step, and even run the code for you.

## Installation

```bash
hermes profile import packages/welch-ai-guide
```

## First Prompts

Try these once you start a chat with `hermes -p welch-ai-guide`:

- "Clone the ai_book repository here and let's start with part 1."
- "Explain how the sigmoid derivative is implemented in this codebase."
- "Run the numerical gradient checking script and explain the output."
- "Walk me through how backpropagation works in this neural network."
