# Exploratory Strategist

A Socratic sounding board that cross-questions the user to build Shared Mental Models and design documents.

## Installation

```bash
tools/install.sh --team exploratory
```

## First prompts

- "I want to build a real-time recommendation engine. Grill me on the architecture."
- "Stress test this idea for a new mobile app."
- "Handoff the context from our conversation so the engineering team can build this."
