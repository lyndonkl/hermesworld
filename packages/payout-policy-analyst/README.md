# Payout policy analyst (valuation team)

One member of the fifteen-Bot valuation team for Hermes Agent. Judges whether the company returns the right amount of cash to its owners, and in the right form, against the free cash flow to equity it generates.

In a team run it receives jobs from `valuation-orchestrator`, runs its stage, writes the artifacts the job
names, and its answer returns to the orchestrator automatically. You can also open it on its
own and ask it to do its stage for a company you name; it will ask for the inputs it needs.

## Install

Install the whole team from the repository root; the team only works together and only in
the Hermes desktop app with Bot Mode on (Settings → Plugins → Bots):

```bash
tools/install.sh --team valuation
python3 tools/team_models.py valuation --strong <model-id> --fast <model-id>   # optional model tiers
```

This member's tier is **fast**. `tools/install.sh` also writes the profile's Bot
metadata (title and role) so teammates see it in their roster.
